# AndroidUygulama

C# ve .NET MAUI ile geliştirilmiş çok sayfalı mobil uygulama (Bartın Üniversitesi Bilgisayar Mühendisliği, Ödev 1).

## Sayfalar

- **Kredi Hesaplama** – kredi türü, tutar, yıllık faiz ve vadeye göre aylık taksit, toplam ödeme ve toplam faiz
- **Renk Seçici** – kırmızı / yeşil / mavi tonlarıyla veya rastgele renk oluşturma, HEX renk kodu
- **Vücut Kitle İndeksi** – boy ve kiloya göre VKİ hesabı
- **Yapılacaklar Listesi** – yeni madde ekleme ve kaydetme

## Teknolojiler

C#, .NET 7, .NET MAUI, XAML

## Çalıştırma

1. Visual Studio 2022'de ".NET Multi-platform App UI" iş yükünü kurun.
2. `MauiApp1/MauiApp1.csproj` dosyasını açın.
3. Hedef olarak Android emülatörü veya Windows Machine seçip çalıştırın.
